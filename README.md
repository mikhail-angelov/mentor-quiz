# Ваш тип наставника в Обучении служением

Квиз: 10 вопросов × 5 ответов → ведущий тип наставника + состав с процентами.

- **Стек:** Vite + React + TypeScript
- **Контент:** `src/data.ts` — 5 типов и 10 вопросов (реальный контент, формат «Вы»)
- **Деплой:** GitHub Pages через GitHub Actions (`deploy.yml`), `base: './'`

## Локально

```bash
npm i
npm run dev      # dev-сервер
npm run build    # сборка в dist/
```
